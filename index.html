1. Apa itu Microsoft Excel?

Microsoft Excel adalah aplikasi pengolah angka. Kita dapat menulis data dalam kotak-kotak, membuat tabel, dan menghitung dengan rumus.

Contoh pemakaian: daftar belanja, jumlah buku perpustakaan, atau data nilai.

2. Cerita singkat perkembangannya

DahuluOrang memakai kertas untuk mencatat angka. Lalu muncul aplikasi spreadsheet untuk membantu mengolah data di komputer.
KemudianMicrosoft mengembangkan Microsoft Excel. Aplikasi ini hadir dalam berbagai versi dan terus mendapat kemampuan baru.
SekarangMicrosoft Excel digunakan untuk membuat tabel, mengolah angka, dan menampilkan data dengan lebih mudah.

3. Kenali tempat kerjanya

WorkbookFile Microsoft Excel. Bayangkan seperti sebuah buku.
WorksheetLembar kerja di dalam workbook. Bayangkan seperti satu halaman buku.
SelSatu kotak tempat menulis data. Nama sel menggabungkan huruf kolom dan nomor baris, misalnya B2.

Kolom berjalan dari atas ke bawah dan diberi huruf A, B, C. Baris berjalan dari kiri ke kanan dan diberi angka 1, 2, 3.

4. Lihat contoh tabel

Kolom B berisi jumlah buku. Kotak kuning adalah sel B2: kolom B, baris 2.

5. Buat dan rapikan tabel

Langkah 1Buka worksheet. Tulis judul kolom: Barang di A1 dan Jumlah di B1.
Langkah 2Isi nama barang di kolom A dan angkanya di kolom B. Satu barang pada setiap baris.
Langkah 3Perlebar kolom jika teks terpotong. Tebalkan judul kolom agar mudah dibaca.

6. Hitung jumlah otomatis dengan SUM

Klik sel tempat hasil akan ditampilkan, misalnya B6. Ketik rumus berikut, lalu tekan Enter:

=SUM(B2:B5)

=Tanda sama dengan memberi tahu Microsoft Excel bahwa kita menulis rumus.
SUMNama fungsi untuk menjumlahkan angka.
B2:B5Rentang sel dari B2 sampai B5. Tanda titik dua berarti “sampai”.

Pada contoh, hasilnya 4 + 3 + 2 + 1 = 10. Jika angka dalam rentang berubah, hasil rumus ikut dihitung ulang oleh Microsoft Excel.
